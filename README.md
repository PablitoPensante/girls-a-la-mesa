# Girls a la mesa

Landing page estatica para promocionar el podcast **Girls a la mesa**.

## Como verla

Abre `index.html` directamente en el navegador o ejecuta:

```bash
npm start
```

Luego entra a `http://127.0.0.1:4173`. Tambien puedes publicar esta carpeta en
Netlify, Vercel o GitHub Pages.

## Assets pendientes

Guarda estas imagenes en la carpeta `assets`:

- `logo.png`: logo cuadrado del podcast.
- `characters.png`: ilustracion de las dos chicas para el hero.

## Pendiente por definir con la clienta

- Enlaces reales de Instagram, TikTok y YouTube.
- Si quiere una seccion con varios episodios o solo el episodio destacado.
- Donde se publicara la pagina.
