# Girls a la mesa

Landing page estatica para promocionar el podcast **Girls a la mesa**.

Pagina publicada:

https://pablitopensante.github.io/girls-a-la-mesa/

## Como verla

Abre `index.html` directamente en el navegador o ejecuta:

```bash
npm start
```

Luego entra a `http://127.0.0.1:4173`. Tambien puedes publicar esta carpeta en
Netlify, Vercel o GitHub Pages.

## Assets pendientes

Guarda estas imagenes en la carpeta `assets`:

- `logo.png.jpeg`: logo cuadrado del podcast.
- `characters.png.jpeg`: ilustracion de las dos chicas para el hero.
